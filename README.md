# Week 1 Java Programming

## Overview

This repository contains my Week 1 Java programming assignments and practice programs. The programs demonstrate basic Java concepts such as variables, user input, conditional statements, loops, arrays, strings, and switch-case statements.

## Assignments

### 1. Basic Calculator

- Performs addition, subtraction, multiplication, and division.
- Uses `Scanner` for user input.
- Uses `switch-case` for selecting the operation.

**File:** `Calculator.java`

### 2. Grade Evaluation

- Accepts marks from the user.
- Evaluates the marks using `if-else`.
- Displays the appropriate grade.

**File:** `GradeEvaluation.java`

### 3. Bank Management System

- Deposit money.
- Withdraw money.
- Check account balance.
- Exit the application.
- Uses a menu-driven `switch-case` program.

**File:** `BankManagement.java`

## Practice Programs

1. Even or Odd — `EvenOdd.java`
2. Sum of Array Elements — `ArraySum.java`
3. Reverse a String — `ReverseString.java`
4. Swap Two Numbers Without a Third Variable — `SwapNumbers.java`
5. Multiplication Table — `MultiplicationTable.java`

## Technologies Used

- Java
- Java Scanner
- Conditional Statements
- Loops
- Arrays
- Strings
- Switch-Case

## How to Run

Compile a Java program:

```bash
javac FileName.java
```

Run the program:

```bash
java FileName
```

Example:

```bash
javac Calculator.java
java Calculator
```
